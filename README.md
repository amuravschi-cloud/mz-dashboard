# Metalica Zuev — Дашборд валовой прибыли и продаж

Интерактивный веб-дашборд анализа валовой прибыли компании **Metalica Zuev (MZ)** за 2026 год на базе легковесного клиентского OLAP-движка с шифрованием AES-256-GCM.

- **GitHub репозиторий:** `https://github.com/amuravschi-cloud/mz-dashboard.git`
- **Рабочая ссылка:** `https://amuravschi-cloud.github.io/mz-dashboard/`
- **Пароль по умолчанию:** `MZ2026`

---

## 1. Архитектура проекта

- **Тип приложения:** Статический Single Page Application (SPA).
- **Стек фронтенда:** Pure HTML5, CSS3, Vanilla JavaScript (ES6+), Web Crypto API.
- **Бэкенд:** Не требуется. Работает на любом статическом веб-сервере (Nginx, Caddy, Apache, Docker `nginx:alpine`).
- **Безопасность данных:** Исходные данные агрегированы в многомерный OLAP-куб и зашифрованы алгоритмом **AES-256-GCM** с деривацией ключа **PBKDF2** (100 000 итераций SHA-256, 16 байт соли, 12 байт IV). Расшифровка выполняется на стороне клиента в браузере через стандартный `window.crypto.subtle`.

### Файловая структура репозитория
```text
mz-dashboard/
├── index.html          # Полный веб-интерфейс дашборда со всеми вкладками и OLAP-движком
├── data.enc.js         # Зашифрованный payload данных (подключается через <script>)
├── generate_cube.py    # Python-скрипт сборки OLAP-куба из выгрузок 1С и его шифрования
├── requirements.txt    # Зависимости Python для генератора (pandas, openpyxl, cryptography)
└── README.md           # Документация и инструкция по развертыванию
```

## 2. Источники данных и ETL-пайплайн

Куб формируется скриптом `generate_cube.py` на основе 3 источников:

1. **Выгрузка продаж из 1С** (помесячный регистр с внешними кодами номенклатуры):
   - Колонки: `Контрагент`, `Номенклатура`, `Склад`, `Период`, `Номенклатура.Внешний код (Номенклатура)`, `Сумма без НДС`, `Количество`, `Себестоимость`.
2. **Справочник номенклатуры 1С** (`PBI_SprNomNew.xlsx`):
   - Иерархическое дерево товарных категорий 1С (Арматура, Трубы профильные, Лист, Балка, Швеллер, Круг, Уголок, Трубы круглые, Полоса, Квадрат, Прочее).
3. **Справочник клиентов и менеджеров** (`managers_clients.json`):
   - Привязка контрагентов к ответственным менеджерам и группам доступа («Покупатели металла», «Daske» и др.).
   - Автоматическое разделение на **Опт** (юридические лица) и **Розницу** (частные покупатели по точкам продаж).

### Локальные пути к исходникам на Mac:
- **Выгрузка продаж 1С (факт с кодами):**  
  `/Users/user/Documents/MZ Аналитика/для вал приб 1с бух_коды.xlsx`
- **Справочник номенклатуры 1С (дерево категорий):**  
  `/Users/user/Documents/MZ Аналитика/tmp/PBI_SprNomNew.xlsx`
- **Справочник клиентов, менеджеров и групп доступа:**  
  `/Users/user/Documents/mz_refs_data/managers_clients.json`
- **Нешифрованный куб (JSON):**  
  `/Users/user/Documents/MZ Аналитика/dashboard_cube.json`

### Пути к тем же справочникам на рабочем VPS (`/opt/dashboard/`):
- Справочник номенклатуры уже лежит в: `/opt/dashboard/incoming/PBI_SprNomNew.xlsx`
- Сырые справочники контрагентов лежат в: `/opt/dashboard/dz/raw/` (`customers.json`, `employees.json`, `access_groups_ref.json`)
- Пошаговая инструкция для агента по подключению к Caddy и пулу дашбордов: см. **[`VPS_DEPLOY.md`](VPS_DEPLOY.md)**.

## 3. Запуск генератора куба

Для генерации зашифрованного payload:

```bash
# 1. Установка зависимостей
pip install -r requirements.txt

# 2. Запуск генерации на Mac (по умолчанию берёт локальные файлы):
python3 generate_cube.py

# 3. Или запуск с явными путями (например, на VPS):
python3 generate_cube.py \
  --sales "/opt/dashboard/incoming/для вал приб 1с бух_коды.xlsx" \
  --nom-spr "/opt/dashboard/incoming/PBI_SprNomNew.xlsx" \
  --clients-json "/opt/dashboard/refs/managers_clients.json" \
  --out-cube "dashboard_cube.json" \
  --out-enc "data.enc.js" \
  --password "MZ2026"
```

Скрипт автоматически:
1. Распознает все месяцы (1–12) из колонки «Период».
2. Сопоставит 100% номенклатуры с деревом групп.
3. Сопоставит клиентов с ответственными менеджерами.
4. Разделит потоки на Опт и Розницу.
5. Соберёт компактный OLAP-куб (~36 000 строк агрегатов вместо сотен тысяч сырых строк).
6. Зашифрует результат в `data.enc.js`.

## 4. Развертывание на VPS

Дашборд состоит из двух статичных файлов (`index.html` и `data.enc.js`).

### Вариант А. Через Nginx
Скопируйте репозиторий в папку веб-сервера (например `/var/www/mz-dashboard`):

```nginx
server {
    listen 80;
    server_name mz-profit.yourdomain.com;

    root /var/www/mz-dashboard;
    index index.html;

    # Gzip для ускорения загрузки куба
    gzip on;
    gzip_types text/plain text/css application/javascript application/json;

    location / {
        try_files $uri $uri/ =404;
    }
}
```

### Вариант Б. Через Docker
Создайте `Dockerfile` в папке проекта:
```dockerfile
FROM nginx:alpine
COPY index.html /usr/share/nginx/html/
COPY data.enc.js /usr/share/nginx/html/
EXPOSE 80
CMD ["nginx", "-g", "daemon off;"]
```

Сборка и запуск:
```bash
docker build -t mz-dashboard .
docker run -d -p 8080:80 --name mz-dashboard mz-dashboard
```

## 5. Возможности дашборда

1. **Сводная (Executive Summary)**:
   - Ключевые KPI: Выручка, Себестоимость, Валовая прибыль, % Маржи, Тоннаж, Прибыль на тонну.
   - Карточки Опт vs Розница с долями в прибыли и среднем чеке.
   - Экспресс-таблицы ТОП групп, ТОП оптовых клиентов, ТОП менеджеров.

2. **Товары (Номенклатура)**:
   - Двухуровневая иерархическая таблица (Группы ➔ Позиции).
   - Кнопки «Развернуть все» / «Свернуть все».
   - Мгновенный поиск по номенклатуре и артикулу с авто-раскрытием групп.
   - Корректная иерархическая сортировка по Итого и любому месяцу.

3. **Менеджеры**:
   - Строгое разделение оптовых менеджеров и розничных продаж (с тумблерами).
   - Клик по менеджеру моментально переводит во вкладку «Клиенты» с фильтрацией по его портфелю.

4. **Клиенты**:
   - Полный реестр клиентов с привязкой к менеджерам и выручке.
   - Поиск по названию или менеджеру.
   - Анализ концентрации (ТОП-10, ТОП-20, ТОП-50 клиентов в общей прибыли).

5. **Группы товаров (Экономика ассортимента)**:
   - Коэффициент маржинальности (доля прибыли ÷ доля тоннажа).

6. **Анализ структуры**:
   - Интерактивный симулятор «Что если»: изменение тоннажа по товарным группам с мгновенным пересчётом ожидаемой прибыли компании.

7. **Реактивные сквозные фильтры**:
   - По складам (`Даске`, `Сынжера`, `Транснистрия 3`, `база`, `база Оргеев`).
   - По группам доступа клиентов.
   - По ответственным менеджерам.
   - По месяцам года (с поддержкой любого диапазона 1–12).
   - Кнопка быстрого сброса фильтров.
